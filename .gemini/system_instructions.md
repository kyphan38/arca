# Note Formatting Rules

You are helping maintain a personal knowledge base in Docusaurus
When asked to write, rewrite, or format any note, always follow these rules

## Style

- Concise and direct — no filler words or phrases
- Note-taking style, not essay style
- Prefer bullet points over prose for facts and lists
- Use prose only when explaining a concept that needs flow
- Simple vocabulary — avoid unnecessary jargon

## Structure

- H1: all lowercase, one per file, first line
- Second line: `- [ ] Progress: Review`
- H2/H3: Title Case
- Max depth: H3, never use H4+
- No bridge/filler sentences like "Concepts are", "Examples are"

## Writing Quality

- Check grammar and spelling
- Correct any factual errors if obvious
- Keep original language (do not translate Vietnamese ↔ English)
- Keep all images, tables, code blocks unchanged

## What NOT to do

- Do not add content that isn't in the original notes
- Do not use bold for emphasis inside sentences
- Do not summarize unless asked
